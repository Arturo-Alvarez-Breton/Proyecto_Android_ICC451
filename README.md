# Proyecto Android ICC451

Este proyecto es una aplicación Android desarrollada como parte del curso ICC451. Su objetivo principal es proporcionar una solución eficiente y moderna para la gestión y visualización de información relevante, integrando servicios de Google y otras tecnologías actuales.

## Características principales

- Interfaz intuitiva y fácil de usar.
- Integración con servicios de Google (Maps, autenticación, etc.).
- Gestión segura de datos y usuarios.
- Arquitectura modular y escalable.
- Cumplimiento de buenas prácticas de desarrollo Android.

## Requisitos

- Android Studio (versión recomendada: última estable)
- SDK de Android 8.0 (API nivel 26) o superior
- Conexión a Internet para servicios en la nube

## Instalación

1. Clona este repositorio:
   ```
   git clone https://github.com/tu_usuario/Proyecto_Android_ICC451.git
   ```
2. Abre el proyecto en Android Studio.
3. Configura los servicios de Google agregando tu propio archivo `google-services.json` en la carpeta `app/`.
4. Compila y ejecuta la aplicación en un emulador o dispositivo físico.

## Notas de seguridad

- **No compartas tu archivo `google-services.json` ni claves privadas.** Estos archivos están excluidos del control de versiones por motivos de seguridad.
